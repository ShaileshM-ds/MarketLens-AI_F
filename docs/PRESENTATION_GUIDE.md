# Presentation guide: 5–7 minute demo

**Before you start (2 minutes before):**
- Run `docker compose ps`; all four services should be "healthy".
- Open http://localhost:8080 and choose **Demo** in the mode switcher.
- Open the Analyst dashboard and one Forecast tab once, so their first-time calculations (about 6–8 s) are cached.
- Sign in as your administrator for step 8. There are no default accounts.

**What's synthetic, and what Imported can't do:**
- Everything shown in Demo mode is **synthetic demonstration data**, labelled "Demo · synthetic data" in the top bar.
  - Products, brands, sellers, prices, reviews and the product artwork are all fictional.
  - The planted scenarios (genuine discount, inflated reference price, repeated urgency, synchronized events…) are there to show that the analysis finds them. They are not market findings.
- **Imported** data is a snapshot without timezones, so it has no verified history. For Imported products, Price History, Evidence, Buying advice, Forecast, Seller synchronization and the history-based audit rules show "Insufficient evidence".
  - Only snapshot comparisons and observed-fact audit flags (for example its 44 stock contradictions) are available.
- **Live** mode is unavailable: no provider is configured.

| Time | Click | Say |
|---|---|---|
| 0:00 | **Overview** (/) in Demo | MarketLens compares store listings and checks discounts against observed history. Note the Demo badge and "Featured demo products": synthetic data and artwork. |
| 0:40 | **Product Explorer** → filters, then **Table** view | 40 synthetic products on 3 stores; filters work on the same store listing; prices are stored as integer paise. |
| 1:20 | Open **Zephyra Cotton Tee Size S Graphite** (DEMO-P-001) | Buying advice: *Buy now, high confidence*. The price is about 19% below its usual (median) price. Store rows show base and confirmed delivered prices; unknown shipping is never free. |
| 2:10 | **Evidence** tab | Real Price Detector, Genuine Discount Score (68, "some evidence", because the advertised 38% overstates the real 19%), the evidence table and limitations. Every analysis takes an explicit UTC cutoff. |
| 2:50 | **Timeline** tab → scrub back, press **Play** | The Time Machine reconstructs observed state at any past time and never shows later observations. |
| 3:20 | **Forecast** tab → 7 / 14 / 30 days | Estimates are labelled "Forecast, not observed". Each listing picks its model from its own backtest; for this one the last observed price (baseline) wins, so the baseline is used. The range is a *nominal* 80% with measured coverage below that, shown as "Not calibrated". |
| 4:00 | Open **DEMO-P-002** → Pricing practices audit | An inflated reference price: the price didn't move but the "MRP" rose 50%. Calculated findings with ordinary explanations; flags, not accusations. |
| 4:30 | **Analyst dashboard** | Workspace summaries at a cutoff: detector verdicts, advice, audit findings, synchronization patterns (DEMO-P-007: planted store-wide events, "worth investigating, not proof"), and forecast accuracy against the baseline. |
| 5:20 | **Data administration** (signed in) | Imports go only to Imported; Demo is generated by a seeded generator and can be reset with a typed confirmation; quarantined rows have plain reasons. |
| 5:50 | **Methodology** | Every formula and threshold on this page is read from the code. The forecast evaluation table shows previous → calibrated coverage *and* width: coverage improved only with wider ranges. |
| 6:30 | Switch the mode to **Imported** and open any product | Snapshot-only data: history-based features say "Insufficient evidence" instead of inventing results. |

**If something looks slow:** the first dashboard or forecast load per cutoff computes and caches (about 6–8 s); later loads are instant.
